## Connector endpoint

- **Endpoint:** Shopify · `orders`
- **Default destination table:** `shopify_orders`
- **Unique keys:** `id`
- **Time series:** yes, loaded by date range

# Schema

| Column | Type | Description |
|--------|------|-------------|
| `id` | STRING | PK. A globally-unique ID. |
| `name` | STRING | The order name, generated by combining the order_number with the shop order prefix. |
| `email` | STRING | The email address of the customer. |
| `phone` | STRING | The phone number of the customer. |
| `displayFinancialStatus` | STRING | The financial status of the order. |
| `displayFulfillmentStatus` | STRING | The fulfillment status of the order. |
| `confirmed` | BOOLEAN | Whether the order is confirmed. |
| `closed` | BOOLEAN | Whether the order is closed. |
| `cancelledAt` | TIMESTAMP | The date and time when the order was cancelled. |
| `cancelReason` | STRING | The reason for cancellation. |
| `currencyCode` | STRING | The currency of the order. |
| `subtotalPrice` | NUMERIC | The subtotal price of the order. |
| `totalPrice` | NUMERIC | The total price of the order. |
| `totalTax` | NUMERIC | The total tax of the order. |
| `totalShippingPrice` | NUMERIC | The total shipping price. |
| `totalDiscounts` | NUMERIC | The total discounts applied. |
| `discountCodes` | STRING | Discount codes applied to the order as JSON array (code, amount, type). |
| `discountApplications` | STRING | All discount applications (codes, automatic, manual) as JSON array. |
| `totalRefunded` | NUMERIC | The total amount refunded. |
| `totalOutstanding` | NUMERIC | The total amount not yet transacted for the order. |
| `totalWeight` | NUMERIC | The total weight of the order. |
| `fullyPaid` | BOOLEAN | Whether the order is fully paid. |
| `taxesIncluded` | BOOLEAN | Whether taxes are included in the order subtotal. |
| `taxExempt` | BOOLEAN | Whether the order is tax exempt. |
| `customerId` | STRING | The ID of the customer. |
| `customerEmail` | STRING | The email of the customer. |
| `shippingAddressCity` | STRING | City from the shipping address. |
| `shippingAddressCountry` | STRING | Country from the shipping address. |
| `shippingAddressProvince` | STRING | Province from the shipping address. |
| `shippingAddressZip` | STRING | Postal/ZIP code from the shipping address. |
| `billingAddressCity` | STRING | City from the billing address. |
| `billingAddressCountry` | STRING | Country from the billing address. |
| `billingAddressProvince` | STRING | Province from the billing address. |
| `billingAddressZip` | STRING | Postal/ZIP code from the billing address. |
| `tags` | STRING | A comma-separated list of tags. |
| `note` | STRING | The note attached to the order. |
| `sourceName` | STRING | The source of the order. |
| `processedAt` | TIMESTAMP | The date and time when the order was processed. |
| `closedAt` | TIMESTAMP | The date and time when the order was closed. |
| `createdAt` | TIMESTAMP | The date and time when the order was created. |
| `updatedAt` | TIMESTAMP | The date and time when the order was last updated. |
| `customer` | STRING | Full customer object as JSON (id, email, phone, defaultAddress). |
| `currentTotalDiscounts` | NUMERIC | The current total discounts (after edits). |
| `currentTotalTax` | NUMERIC | The current total tax (after edits). |
| `lineItems` | STRING | The line items in the order as JSON array. |
| `shippingLines` | STRING | Shipping lines as JSON array. |
| `refunds` | STRING | Refunds as JSON array. |

# Example Questions

- What were net sales, tax and shipping per month, and how much of it was refunded?
- Which discount codes brought in the most revenue, and what share of orders used one?
- How many orders sit in each financial and fulfillment status, and how old is the oldest unfulfilled one?
