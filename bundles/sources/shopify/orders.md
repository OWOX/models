title: "Orders"
description: |
  One row per order placed in the store: financial and fulfillment status, order totals (subtotal, tax, shipping, discounts, refunded), currency, customer contact fields, billing and shipping location, tags, source and the key timestamps. Detail that has no column of its own is kept as JSON text: the line items, shipping lines, refunds and discount applications. `discountCodes` lists the codes used as plain comma-separated text, and `customer` holds only the customer's ID.

  Every money column is in the store currency (`currencyCode`). Several amounts come in families: `totalPrice` is before returns, `currentTotalPrice` after returns and refunds, and `originalTotalPrice` as at order creation; each field's description says which it is. `customerId` points to Customers, and Fulfillment Orders, Tender Transactions and Order Metafields point back here on the order `id`. The `id` is Shopify's global ID, a string such as `gid://shopify/Order/…`, not a number.

## Connector endpoint

- **Endpoint:** Shopify · `orders`
- **Default destination table:** `shopify_orders`
- **Last updated:** 2026-10-07 — last change to this endpoint's entry in the connector's fields schema, or to the file that declares its fields ([16d8a24f5](https://github.com/OWOX/owox-data-marts/commit/16d8a24f53f20dc6a92847cbb1b891b4d666cf88))
- **Shopify Admin GraphQL API version:** 2026-07
- **Unique keys:** `id`
- **Time series:** yes, loaded by date range

# Schema

| Column | Type | Alias | Description |
|--------|------|-------|-------------|
| `id` | STRING | ID | PK. A globally-unique ID. |
| `name` | STRING | Name | The order name, generated by combining the order_number with the shop order prefix. |
| `email` | STRING | Email | The email address associated with the customer for this order; empty when none was provided at checkout. `customerEmail` is the linked customer account's address. |
| `phone` | STRING | Phone | The phone number associated with the customer for this order, not read from the linked customer account; empty when none was provided at checkout. The customer account's phone is `phone` in [Customers](./customers.md), via `customerId`. |
| `displayFinancialStatus` | STRING | Display Financial Status | The financial status of the order. |
| `displayFulfillmentStatus` | STRING | Display Fulfillment Status | The fulfillment status of the order. |
| `confirmed` | BOOLEAN | Confirmed | Whether the order is confirmed. |
| `closed` | BOOLEAN | Closed | Whether the order is closed. |
| `cancelledAt` | TIMESTAMP | Cancelled At | The date and time when the order was cancelled. |
| `cancelReason` | STRING | Cancel Reason | The reason for cancellation. |
| `currencyCode` | STRING | Currency Code | The store currency when the order was placed; every money column of this table is in it. |
| `subtotalPrice` | FLOAT | Subtotal Price | Sum of the line-item prices after discounts and before returns, in the store currency; `currentSubtotalPrice` is after returns and refunds. |
| `totalPrice` | FLOAT | Total Price | Total price of the order, including taxes and discounts, before returns, in the store currency; `currentTotalPrice` is after returns, `originalTotalPrice` at order creation. |
| `totalTax` | FLOAT | Total Tax | Total tax before returns, in the store currency; `currentTotalTax` is after returns and refunds. |
| `totalShippingPrice` | FLOAT | Total Shipping Price | The total shipping costs returned to the customer, in the store currency (Shopify `totalShippingPriceSet`); `currentShippingPrice` is the current shipping price after refunds and discounts. |
| `totalDiscounts` | FLOAT | Total Discounts | Total discounted on the order before returns, in the store currency; `currentTotalDiscounts` is after returns and refunds, and `cartDiscountAmount` holds the order-level part only. |
| `discountCodes` | STRING | Discount Codes | The discount codes used on the order, as comma-separated text without amounts or types; `discountApplications` holds those as JSON. |
| `discountApplications` | STRING | Discount Applications | Every discount applied to the order (codes, automatic, manual, script) as a JSON array of up to 20, ordered by index; each one's `targetType` says whether it applies to line items or to shipping lines. |
| `totalRefunded` | FLOAT | Total Refunded | The total amount refunded. |
| `totalOutstanding` | FLOAT | Total Outstanding | The total amount not yet transacted for the order. |
| `totalWeight` | FLOAT | Total Weight | Total weight of the order before returns, in grams; `currentTotalWeight` is after returns and refunds. |
| `fullyPaid` | BOOLEAN | Fully Paid | Whether the order is fully paid. |
| `taxesIncluded` | BOOLEAN | Taxes Included | Whether taxes are included in the order subtotal. |
| `taxExempt` | BOOLEAN | Tax Exempt | Whether the order is tax exempt. |
| `customerId` | STRING | Customer ID | The ID of the customer. FK to [Customers](./customers.md) |
| `customerEmail` | STRING | Customer Email | The email of the customer account linked to the order; empty when the order has no customer, and it can differ from the order's own `email`. |
| `shippingAddressCity` | STRING | Shipping Address City | City from the shipping address. |
| `shippingAddressCountry` | STRING | Shipping Address Country | Country from the shipping address. |
| `shippingAddressProvince` | STRING | Shipping Address Province | Province from the shipping address. |
| `shippingAddressZip` | STRING | Shipping Address Zip | Postal/ZIP code from the shipping address. |
| `billingAddressCity` | STRING | Billing Address City | City from the billing address. |
| `billingAddressCountry` | STRING | Billing Address Country | Country from the billing address. |
| `billingAddressProvince` | STRING | Billing Address Province | Province from the billing address. |
| `billingAddressZip` | STRING | Billing Address Zip | Postal/ZIP code from the billing address. |
| `tags` | STRING | Tags | A comma-separated list of tags. |
| `note` | STRING | Note | The note attached to the order. |
| `sourceName` | STRING | Source Name | The source of the order. |
| `checkoutToken` | STRING | Checkout Token | Token of the checkout that created the order. Useful for correlating the order with Web Pixel checkout events. NULL when no checkout is associated. |
| `cartToken` | STRING | Cart Token | Token of the cart that was used to create the order. NULL when no cart is associated. |
| `processedAt` | TIMESTAMP | Processed At | The date and time when the order was processed. |
| `closedAt` | TIMESTAMP | Closed At | The date and time when the order was closed. |
| `createdAt` | TIMESTAMP | Created At | The date and time when the order was created. |
| `updatedAt` | TIMESTAMP | Updated At | The date and time when the order was last updated. |
| `customer` | STRING | Customer (ID Only) | The ID of the order's customer, the same value as `customerId`: the connector requests the customer's contact and address but keeps only the ID. |
| `currentTotalDiscounts` | FLOAT | Current Total Discounts | Total discounted on the order after returns and refunds, in the store currency; `totalDiscounts` is the amount before returns. |
| `currentTotalTax` | FLOAT | Current Total Tax | Tax on the order's line items after returns and refunds, in the store currency; `totalTax` is the amount before returns. |
| `number` | INTEGER | Number | The order number used to generate the order name (with the shop's order number prefix/suffix). Not guaranteed to be unique. |
| `confirmationNumber` | STRING | Confirmation Number | A customer-facing order identifier, shown in some surfaces instead of the sequential order name. Not guaranteed to be unique. |
| `legacyResourceId` | STRING | Legacy Resource ID | The ID of the corresponding resource in the REST Admin API. |
| `test` | BOOLEAN | Test | Whether the order was placed in test mode. |
| `edited` | BOOLEAN | Edited | Whether the order has had any edits applied after creation. |
| `originalTotalPrice` | FLOAT | Original Total Price | The total price of the order at the time it was created. |
| `currentTotalPrice` | FLOAT | Current Total Price | The total price of the order, after returns. |
| `netPayment` | FLOAT | Net Payment | The net payment for the order (total received minus total refunded). |
| `totalReceived` | FLOAT | Total Received | The total amount received from the customer before returns. |
| `totalCapturable` | FLOAT | Total Capturable | The authorized amount that hasn't been captured yet. |
| `totalTipReceived` | FLOAT | Total Tip Received | The sum of all tip amounts for the order. |
| `currentSubtotalPrice` | FLOAT | Current Subtotal Price | Subtotal of the order after returns and refunds, in the store currency; `subtotalPrice` is the amount before returns. |
| `cartDiscountAmount` | FLOAT | Cart Discount Amount | The total order-level (cart) discount amount applied at the time the order was created. Does not include line-level discounts. |
| `currentCartDiscountAmount` | FLOAT | Current Cart Discount Amount | The current order-level (cart) discount amount after returns, refunds, order edits and cancellations. Does not include line-level discounts. |
| `currentShippingPrice` | FLOAT | Current Shipping Price | The current shipping price, after refunds and discounts. |
| `totalRefundedShipping` | FLOAT | Total Refunded Shipping | The total amount of shipping that was refunded. |
| `currentTotalDuties` | FLOAT | Current Total Duties | The current total import duties for the order, after returns or modifications. |
| `originalTotalDuties` | FLOAT | Original Total Duties | The total import duties calculated when the order was created. |
| `currentTotalAdditionalFees` | FLOAT | Current Total Additional Fees | The current total of all additional fees for the order. |
| `originalTotalAdditionalFees` | FLOAT | Original Total Additional Fees | The total of all additional fees calculated when the order was created. |
| `refundDiscrepancy` | FLOAT | Refund Discrepancy | The difference between the suggested and the actual refunded amount. Positive values favor the merchant, negative values favor the customer. |
| `presentmentCurrencyCode` | STRING | Presentment Currency Code | The currency the customer used when placing the order. Amount fields in this table are in the shop currency (currencyCode). |
| `unpaid` | BOOLEAN | Unpaid | Whether no payments have been made for the order. |
| `refundable` | BOOLEAN | Refundable | Whether the order can be refunded based on its payment transactions. |
| `capturable` | BOOLEAN | Capturable | Whether an authorized payment on the order can be captured. |
| `canMarkAsPaid` | BOOLEAN | Can Mark As Paid | Whether the order can be manually marked as paid. |
| `paymentGatewayNames` | STRING | Payment Gateway Names | The names of all payment gateways used for the order, comma-separated. |
| `estimatedTaxes` | BOOLEAN | Estimated Taxes | Whether taxes on the order are estimated. |
| `fulfillable` | BOOLEAN | Fulfillable | Whether the order has any line items that can be fulfilled. |
| `requiresShipping` | BOOLEAN | Requires Shipping | Whether the order requires physical shipping. |
| `subtotalLineItemsQuantity` | INTEGER | Subtotal Line Items Quantity | The sum of quantities for all line items contributing to the subtotal. |
| `currentSubtotalLineItemsQuantity` | INTEGER | Current Subtotal Line Items Quantity | The current sum of quantities for all line items contributing to the subtotal, after returns. |
| `currentTotalWeight` | FLOAT | Current Total Weight | The total weight of the order in grams, after returns and refunds. |
| `restockable` | BOOLEAN | Restockable | Whether any line items on the order can be restocked into inventory. |
| `canNotifyCustomer` | BOOLEAN | Can Notify Customer | Whether order notifications can be sent to the customer. |
| `statusPageUrl` | STRING | Status Page URL | The URL where the customer can check the order's current status. |
| `hasTimelineComment` | BOOLEAN | Has Timeline Comment | Whether the merchant added a timeline comment to the order. |
| `merchantEditable` | BOOLEAN | Merchant Editable | Whether the order can be edited by the merchant. |
| `merchantEditableErrors` | STRING | Merchant Editable Errors | Reasons why the order can't be edited, comma-separated. Empty when the order is editable. |
| `dutiesIncluded` | BOOLEAN | Duties Included | Whether duties are included in the subtotal price of the order. |
| `poNumber` | STRING | PO Number | The purchase order number associated with the order. |
| `sourceIdentifier` | STRING | Source Identifier | A unique POS or third-party order identifier. |
| `registeredSourceUrl` | STRING | Registered Source URL | The URL of the source the order originated from. |
| `productNetwork` | BOOLEAN | Product Network | Whether the customer purchased items from other stores in the same network. |
| `customerAcceptsMarketing` | BOOLEAN | Customer Accepts Marketing | Whether the customer agreed to receive marketing emails at the time of purchase. |
| `customerLocale` | STRING | Customer Locale | The customer's language and region preference at the time of purchase. |
| `billingAddressMatchesShippingAddress` | BOOLEAN | Billing Address Matches Shipping Address | Whether the billing address matches the shipping address. False when either address is missing. |
| `lineItems` | STRING | Line Items | The order's line items as a JSON array of up to 250, each with quantity, unit prices before and after discounts and its discount allocations; an allocation points to `discountApplications` by index. |
| `shippingLines` | STRING | Shipping Lines | The order's shipping lines as a JSON array of up to 50, each with its title and price before and after discounts. |
| `refunds` | STRING | Refunds | The order's refunds as a JSON array of up to 50, each with its time, note, total and the line items refunded. |

# Example Questions

- What were net sales, tax and shipping per month, and how much of it was refunded?
- Which `discount codes` brought in the most revenue, and what share of orders used one?
- How many orders sit in each financial and fulfillment status, and how old is the oldest unfulfilled one?

## Joins

- [Customers](./customers.md) — `customerId = id` [N:1] — The customer who placed the order; empty when the order has none.
