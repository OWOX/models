OWOX Model Canvas — free data modeling canvas

OWOX Model Canvas is a free online canvas for designing analytics data models. Draw your data marts (tables, views, SQL or connector outputs) and the joins between them, switch to a field-level ERD view, and import or export the model as Open Knowledge Format (OKF) or Apache Ossie. It works in the browser with no sign-in. An OWOX API key is only needed to push a model into OWOX Data Marts.

What you can do

  • Draw data marts and joinable relationships on a Miro-like canvas, with a field-level ERD view (columns, primary keys, join keys).
  • Start from a template: E-commerce, SaaS, Marketplace, Marketing / Lead-gen, Mobile / Gaming, Finance, Healthcare, and public datasets. The full catalog with descriptions is at owox.com/data-models.
  • Import and export Open Knowledge Format (OKF) bundles: Markdown files with YAML frontmatter, one per data mart, readable in a pull request.
  • Import and export Apache Ossie semantic models (.yaml / .json), including calculated fields, to move a model to and from tools such as dbt, Snowflake and Lightdash.
  • Generate a model with AI: copy a short brief into Claude, ChatGPT or Gemini and import what it returns. See the AI build guide.
  • Get Insight Questions: the business questions a model can answer, generated from schema metadata only. No row-level data leaves your browser.
  • Share a model as a link that reopens the exact diagram, and push it into OWOX Data Marts as drafts.

Frequently asked

Is OWOX Model Canvas free? Yes. The whole canvas is free and works without signing in. An OWOX API key is only needed to push your model into OWOX Data Marts.

Do I need an account to use it? No. You can design models, use templates, get AI question suggestions, and share a link anonymously. Only pushing into OWOX requires an API key.

What is OKF (Open Knowledge Format)? Open Knowledge Format (OKF) is an open specification published by Google that describes a data model as a folder of Markdown files with YAML frontmatter. OWOX Model Canvas imports and exports OKF bundles, so your model stays portable. The canvas is an independent OWOX project, not affiliated with Google. See the OKF format guide.

What is Apache Ossie? Apache Ossie (formerly Open Semantic Interchange) is a vendor-neutral YAML/JSON standard for semantic models — datasets, fields, relationships and metrics — from the Apache Software Foundation, where it is an incubating project. OWOX Model Canvas imports and exports it so your model can move to and from tools such as dbt, Snowflake, Power BI and Lightdash. See the Ossie format guide.

Can I share a data model? Yes. The Share button copies a link that reopens your exact model — layout included — for anyone who opens it, no sign-in required.
